# Security

Please report vulnerabilities privately, not in public issues. Use GitHub's
**Report a vulnerability** button on the repository's Security tab, or email
support@300sf.se.

Include what you found, how to reproduce it, and what an attacker could do with
it. You'll get an answer within a week. Fixes go out in the next release, and
you'll be credited in CHANGELOG.md unless you'd rather not be.

Only the latest release is supported.
